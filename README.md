Hangman - C Programming Project

A console-based word guessing game developed using C programming.

Features

- Random word selection
- Six incorrect guesses allowed
- Interactive hangman drawing
- Letter validation
- Prevention of repeated guesses
- Scoreboard tracking wins and losses
- Option to replay the game

Technologies Used

- C Programming
- Standard C Libraries

How to Run

Compile:

gcc -Wall hangman.c -o hangman

Run:

./hangman
